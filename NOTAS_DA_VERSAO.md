## Ferramentas 1Doc (Rust) 1.1.0

Primeira versão em Rust do Ferramentas 1Doc. Ela faz o mesmo que a versão
Python 1.1.0, com as mesmas quatro abas, as mesmas regras e as mesmas
planilhas. O programa é um único executável, sem Python embutido: abre mais
rápido e costuma alarmar menos o antivírus.

As duas versões podem ficar instaladas juntas. Elas usam a mesma pasta de
dados, então a sessão do 1Doc e os caches valem para as duas: quem já entrou
pela versão Python não precisa entrar de novo.

**Instalação:** baixe o `Ferramentas1Doc-Rust-Setup-1.1.0.exe` abaixo e
execute. Não precisa ser administrador nem instalar o Visual C++
Redistributable: o que o programa usa dele já vai dentro do executável. O atalho no menu Iniciar se chama
*Ferramentas 1Doc (Rust)*. Se o Windows avisar "O Windows protegeu o
computador", clique em *Mais informações → Executar assim mesmo*.
